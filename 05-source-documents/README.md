# Editable Source Documents

This directory contains the editable source files corresponding to reader-facing PDFs elsewhere in the library.

## Preservation rules

1. Never overwrite an original work-experience source file during PDF generation.
2. Generate reader PDFs as separate files.
3. Verify protected source files against `catalog/source-checksums.sha256` before and after migration.
4. Preserve Paytm and other employer-related narratives verbatim unless the owner explicitly requests a content edit.
5. Keep the repository private.
